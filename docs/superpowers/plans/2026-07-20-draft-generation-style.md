# Улучшение стиля генерации постов (Draft Agent) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Убрать выдумывание фактов и дублирование структуры в сгенерированных постах `/draft`, дать модели легитимный путь для LIFE-постов без цифр, поднять целевую длину под то, как автор реально пишет, и проверить, снимает ли более сильная модель Workers AI (`gpt-oss-120b`) остаточные дефекты следования инструкциям.

**Architecture:** Точечные правки трёх мест: system-промпт (`voice.md` + рантайм-копия `src/voice.ts`), user-сообщение в `src/lib/ai.ts`, и константа модели там же. Никакой новой архитектуры/абстракций — Draft Agent как был однопроходным вызовом `env.AI.run()`, так и остаётся.

**Tech Stack:** TypeScript, Cloudflare Workers AI (`env.AI` binding), Vitest (`@cloudflare/vitest-pool-workers`), Wrangler.

Спека: [docs/superpowers/specs/2026-07-20-draft-generation-style-design.md](../specs/2026-07-20-draft-generation-style-design.md)

## Global Constraints

- Не переходим на Claude — `src/lib/claude.ts` не трогаем (не используется, вне фокуса).
- Не меняем `resolveMaterial`/inbox — фокус только на генерации.
- Не добавляем двухэтапную генерацию (отдельный вызов модели на «поиск угла») — избыточно для текущего масштаба.
- Не делаем `run()` в `src/lib/ai.ts` универсальным к разным форматам ответа моделей заранее — только под то, что реально понадобится после смоук-теста (Task 3).
- `voice.md` (человеку) и `src/voice.ts`/`STYLE_GUIDE` (рантайм-копия для Draft Agent) — всегда синхронны по содержанию правил; Worker не читает `.md`-файл.
- Заголовок-строка и подпись `Train. Think. Explore.` — обязательны всегда, без исключений (только требование к цифрам зависит от рубрики).
- Секреты (`.dev.vars`, значения `WEBHOOK_SECRET`/`OWNER_USER_ID`/`BOT_TOKEN`) не печатать в чат/логи, не коммитить.
- `git add` только поимённо; коммиты на русском, инкрементально — один коммit = одно логическое изменение.
- Автотестов на «качество» текста не существует и не нужно — финальная проверка стиля ручная (Task 4), с явным одобрением автора перед тем как считать работу завершённой.

### Task 1: Убрать дублирование структуры в user-сообщении (`src/lib/ai.ts`)
