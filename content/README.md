# content/posts — корпус реальных постов канала

34 поста, 6948 слов. Один пост — один файл, имя `NN_slug.md`, внутри только текст,
как он ушёл в канал.

Этот файл лежит **рядом** с папкой, а не внутри неё: `ai-cadence-check.py --baseline-dir`
читает все `.md` в папке подряд, и документация внутри попадала бы в замер как
авторский текст.

## Кто этим пользуется

| Потребитель | Как |
|---|---|
| Draft Agent бота | `scripts/gen-voice-examples.mjs` берёт 4 эталона и вшивает их в `src/voice-examples.generated.ts` при сборке |
| «Скилл статей» | `statejnik/config.yaml` → `voice.source` (тон-матчинг) и `tools.originality.corpus` (проверка оригинальности) |

**Поэтому корпус живёт в проекте, а не в `statejnik/`.** От него зависит сборка
Worker, значит он должен версионироваться вместе с кодом, а папка скилла остаётся
съёмной.

## Правила пополнения

- Один пост = один файл, имя `NN_slug.md` с продолжением нумерации.
- **Только текст поста.** Без markdown-заголовков вида `## 1 - EXPLORE (Луксор)`,
  без служебных комментариев и разделителей `---`: тире из такой обвязки
  засчитывается инструментом как маркер в авторском тексте.
- Подпись `Train. Think. Explore.` и эмодзи оставлять — это часть голоса.
- Переименовывать файлы-эталоны осторожно: они перечислены в шапке
  `scripts/gen-voice-examples.mjs`, и `npm test` упадёт, если файл не найдётся.
- **Тире и «ё» запрещены.** `lintCorpus` в том же скрипте проверяет всю папку
  и роняет `npm test`, называя файл и число нарушений. Правило не косметическое:
  корпус кормит и промпт бота, и тон-матчинг «Скилла статей», поэтому один
  чужой пост с «ё» тихо учит нарушать правило сразу обоих. Так в корпус когда-то
  и попали 10 «ё» — вместе с текстами из старого `content/real-posts.md`.

## Калибровка после пополнения

```bash
PYTHONIOENCODING=utf-8 py statejnik/tools/ai-cadence-check.py --baseline-dir content/posts
```

Замер по текущему корпусу:

| Категория маркера | Всего |
|---|---|
| антитезы «не X, а Y» | 9 |
| параллелизмы | 2 |
| одиночные слова через точку | 0 |
| литобороты | 0 |
| канцелярит | 0 |
| безличное / крючки «вы узнаете» | 0 |
| длинное и короткое тире | 0 |

Плотность 2.91 маркера на 1000 слов, средняя длина предложения 8.8 слова.
Тире и буквы «ё» в корпусе нет ни одной — это держит `lintCorpus`.

**Как читать эти числа.** Четыре нулевые категории — главный сигнал: у автора их
не бывает вообще, поэтому любое ненулевое значение в новом тексте означает
«переписать», независимо от суммарного порога. Антитеза «не X, а Y» — наоборот,
родная авторская конструкция, поэтому порог `tools.cadence.max_per_1k` стоит
с запасом. Короткие посты завышают плотность на 1000 слов — смотреть и на
абсолютное число маркеров.

## Соседние источники стиля

| Файл | Что это |
|---|---|
| `voice.md` | **Гайд** стиля: правила, стоп-лист, инструкция для Draft Agent. Не образец. |
| `src/voice.ts` | `STYLE_GUIDE` — рантайм-копия **правил** из `voice.md`. Синхронизируется руками. |
| `src/voice-examples.generated.ts` | Эталоны, собранные из этого корпуса. Не править руками. |
