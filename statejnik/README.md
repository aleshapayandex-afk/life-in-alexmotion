# Скилл статей

**Навык для ИИ-агента, который пишет SEO-статьи под ключ.** Вы подключаете его к своему проекту, говорите тему (или не говорите - он выберет сам по свежим сигналам рынка), и агент проходит 16 этапов: находит тему, исследует, пишет, вычитывает семью QA-проходами, гоняет цикл хуманизации, прогоняет финальный независимый каскад редактуры, проверяет рендер и публикует. На выходе - статья, которая закрывает дыру в поисковой выдаче, звучит как живой человек и ведёт читателя к вашему офферу.

Это не генератор текста «по кнопке». Это перенесённый в файлы **процесс**, обкатанный на живой контент-операции в сотни статей. Вся специфика стека и бренда вынесена в один `config.yaml` - поэтому процесс работает в любом проекте и любой нише.

---

## Запуск за 1 шаг

1. Положите папку `statejnik/` в корень проекта (в Claude Code - в `.claude/skills/statejnik/`).
2. Откройте `AUTOPILOT.md` и следуйте инструкции: вставьте промпт-установщик в агента.
3. Автопилот сам просканит проект, задаст минимум вопросов (до восьми) и соберёт `config.yaml`.
4. Скажите: **«напиши статью про <тему>»** - и агент пойдёт по методологии.

Без автопилота: скопируйте `config.example.yaml` в `config.yaml`, заполните руками по комментариям, и навык готов.

| `config.example.yaml` | Схема конфига - единственное место вашей специфики (домен, аудитория, голос, оффер, стоп-слова, способ публикации, юрисдикция, финальный каскад, отчёты). |
| `SKILL.md` | Манифест навыка для Claude Code: триггер-фразы + autonomous-режим. |
| `methodology/00-methodology-16-stages.md` | Сам процесс. 16 этапов в 4 фазах: Поиск → Выбор → Написание → Валидация. |
| `methodology/editorial-standard.md` | Приоритетный редакционный стандарт v3: смысл, язык, структура, факты, SEO-эвристики. Старше механических квот. |
| `methodology/topic-selection.md` | Ежедневный отбор тем по свежим сигналам: уровни доказательств, резервы слотов, правило двух попыток, разбор внешних видео без рерайта. |
| `methodology/final-review.md` | Финальный независимый каскад: редактор (другая модель) + свежий проверяющий до публикации, контроль версии по SHA-256. |
| `methodology/owner-report.md` | Одно короткое уведомление владельцу: формат, честные провалы, без технических логов. |
| `checklists/` | Чек-листы качества: anti-AI (с боевыми паттернами метронома и антитез), SEO/GEO, конверсионная структура (CTA), соответствие (compliance), юр-модуль РФ (legal-ru), физический чек-лист на 50+ пунктов. |
| `tools/` | Скрипты проверки текста: оригинальность, читаемость вслух, детектор AI-почерка. Чистый Python 3, без зависимостей. |
| `templates/` | Скелеты заголовка, структуры и черновика. |

## 4 фазы, 16 этапов (коротко)

1. **Поиск** - свежий пул тем каждый день по сигналам рынка (поисковые подсказки, официальные релизы, внешний контент, вопросы аудитории) + большой заход на 20+ кандидатов для пересборки портфеля. Честные уровни доказательств: измеренный спрос / косвенный / неизвестно.
2. **Выбор** - взвешивание по 9 осям (включая вирусность), агент сам берёт победителя; резерв слота и правило двух попыток: слабую тему ради расписания не пишем.
3. **Написание** - заголовок human-first (3 варианта для A/B) → deep research → структура по задаче → полный текст.
4. **Валидация** - 7 QA-агентов параллельно (включая self-disclosure: внутренности бизнеса наружу не идут) → цикл хуманизации → визуальная проверка рендера → финальный независимый каскад редактуры другой моделью с контролем версии → публикация со сверкой удалённого содержимого → SEO/compliance/AI-detection аудиты → одно короткое уведомление владельцу → самообучение.

Каждая фаза - gate: следующая не стартует, пока не закрыта предыдущая. Подробно - в `methodology/00-methodology-16-stages.md` и документах приоритета рядом с ним.

## Что нужно от вас

- ИИ-агент с доступом к файлам (Claude Code или аналог).
- Python 3 для инструментов проверки (опционально, но рекомендуется).
- 3-5 ваших текстов для тон-матчинга (опционально - без них тон нейтральный).
- Способ публикации: руками, WordPress, Ghost, Notion или свой адаптер.
